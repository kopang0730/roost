这个版本补上了三类日常最需要的能力：**一键修复 Roblox**、**窗口聚焦与平铺**、**应用内检查更新**；文档也改成了中英双语。

## 新增

**一键修复 / 更新 Roblox。** 当本机 Roblox 落后于官方版本（或干脆没装）时，详情页会出现提示条，点「修复 / 更新」就会从官方 CDN 下载约 150 MB 的客户端包、解压、校验版本号，再以原子方式替换 `/Applications/Roblox.app`。

替换过程是安全的：先 `ditto` 到 `.roost-new`，把旧的改名为 `.roost-old`，新的就位后才删旧的——中途失败不会让你没有 Roblox。三道守卫：有实例在跑时拒绝、`/Applications` 不可写时报错、下载到的版本与官方不一致时中止。日志里有百分比进度。

**窗口聚焦。** 右键账号 →「聚焦窗口」，把这个实例提到最前，不用再 Cmd+Tab 找。

**一键平铺。** 工具栏「平铺」会把所有运行中的实例重新铺成网格；屏幕放不下时自动改成层叠，不会完全重叠。

**应用内检查更新。** 启动时读 GitHub Releases，有新版本就在详情页顶部提示，并给出下载链接。账号数据不受影响。

## 改进

- README 拆成英文（默认）与简体中文，顶部可切换；架构文档同样双语
- 打包不再用 `hdiutil -srcfolder`（CI 上会偶发 `Resource busy`），改成建空镜像 → 挂载 → 拷贝 → 压缩，DMG 体积从 20 MB 降到 16.5 MB

## 修复

- 修复 CI 上偶发的 DMG 创建失败
- 修掉 Swift 6 对预览计时器捕获 `self` 的警告

## 升级说明

覆盖安装即可，账号、FFlags、会话都在原位置，无需迁移。

## 安装

下载 `Roost-1.0.1.dmg`，拖进 `Applications`。首次打开需右键 →「打开」。
