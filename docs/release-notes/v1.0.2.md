这个版本主要改授权体验：**Roost 现在会以自己的图标出现在系统隐私列表里**，点一下「去授权」就能把开关打开。

## 新增

**权限引导。** 之前窗口操作是通过 `osascript` 完成的，系统把辅助功能权限算在 `osascript` 头上，所以 Roost 自己根本不会出现在「隐私与安全性」列表里——你只能去给终端授权，体验很别扭。

现在应用会主动调用系统 API 注册自己：

- `AXIsProcessTrustedWithOptions(prompt: true)` → 辅助功能
- `CGRequestScreenCaptureAccess()` → 屏幕录制

缺权限时，详情页顶部会出现橙色提示条，写明「窗口大小、平铺、聚焦需要它」，点「去授权」触发系统弹窗并直接跳到对应面板。Roost 会带着自己的图标出现在列表里，打开开关即可；也可以把 `Roost.app` 直接拖进去。

**设置里的「系统权限」区块。** 两项权限的状态一目了然，随时可以重新授权或跳到设置面板。

## 改进

- Python 运行时（39 MB）不再放在仓库目录里，改到 `~/Library/Application Support/roost/vendor/`。仓库常位于 iCloud Drive，从那里复制会卡在按需下载（实测 2 分 43 秒），移出后完整构建回到 **19 秒**
- `build.sh` 用 `ditto` 复制运行时，减少属性拷贝问题

## 注意

本项目使用 ad-hoc 签名，**每次更新后 macOS 可能把 App 当成新的，需要重新授权一次**，列表里也可能留下旧条目。换成 Developer ID 签名（需 Apple Developer 账号）并公证后，授权可跨版本保留。

## 升级说明

覆盖安装即可。如果你之前在列表里授权的是 `osascript` 或终端，建议把旧条目删掉，用新的「去授权」重新授权一次。

## 安装

下载 `Roost-1.0.2.dmg`，拖进 `Applications`。首次打开需右键 →「打开」。
