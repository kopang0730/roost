首次设置和新手教程更新：集中完成权限准备，再一步步熟悉 Roost。

## 新增与改进

- **首次启动权限清单**：辅助功能、屏幕录制和自动化按行展示，自动更新授权状态，也可选择稍后设置。
- **悬浮授权助手**：点「去授权」后，助手出现在系统设置下方。将 Roost 图标拖进辅助功能或屏幕录制列表，再打开开关；自动化通过系统弹窗确认 System Events 和 Finder。
- **完成设置后的烟花**：开启 macOS「减少动态效果」时显示静态完成提示。
- **六步局部框选教程**：介绍账号、添加账号、启动、性能、维护和设置入口；支持上一步、下一步、跳过及 Esc。设置中可重新播放教程或打开权限引导。没有账号时使用只读示例，结束后自动移除。
- 中英文界面与 DMG 内的首次使用说明同步更新。

## 修复与验证

- 屏幕录制申请在后台执行，系统确认期间可继续显示授权助手；自动化补齐用途说明和申请流程。
- System Events 空闲退出后保留已确认的自动化状态，返回应用时重新检查。
- 禁止内置 Python 写回字节码缓存，避免运行后修改安装包并破坏签名。
- Swift 源文件先复制为构建快照，避免同步目录在编译期间改变输入；发布流程增加引导状态、布局和拖拽类型回归检查。
- 本机实测确认：屏幕录制授权并重启后显示“已授权”，悬浮图标可拖动。

## 安装与升级

下载 **Roost-1.0.3.dmg**，将 Roost.app 拖入 Applications。首次打开按 macOS 提示右键打开或到「隐私与安全性」中允许打开。

应用仍使用 ad-hoc 签名，尚未公证；更新可能需要重新确认系统权限。若系统开关已开启而应用仍提示未授权，在对应权限页移除旧 Roost 条目，再添加 `/Applications/Roost.app` 并授权；按系统提示重新打开应用。原有账号和配置继续保留。

## English

This release adds first-run setup and a guided introduction to Roost.

- A checklist covers Accessibility, Screen Recording and Automation, with live status and a Set up later option.
- A floating permission helper appears below System Settings. Drag the Roost app icon into supported permission lists; approve System Events and Finder through the Automation dialogs.
- Completing setup plays a short celebration, or a static success screen with Reduce Motion.
- A six-step spotlight tour supports Back, Next, Skip and Escape. Replay it or reopen permission setup from Settings. New users see a read-only example account during the tour.
- Screen Recording requests run off the main thread. Automation checks handle an idle System Events process, and the app includes the required Apple events usage description.
- Bundled Python no longer writes bytecode into the signed app. Builds use frozen source snapshots and run onboarding regression checks before publishing.

Download **Roost-1.0.3.dmg** and replace the app in Applications. The app remains ad-hoc signed and unnotarized, so macOS may require permissions again after an update. If a permission is enabled in System Settings but unrecognized in Roost, remove the old entry, add `/Applications/Roost.app` again and grant access, then reopen as prompted. Existing accounts and settings are preserved.
