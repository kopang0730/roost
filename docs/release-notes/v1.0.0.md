首个可分发版本。

## 新增

**内嵌官方登录。** 点工具栏 `+` 直接弹出 Roblox 官方登录页，正常登录（两步验证也能过），登录完成后自动抓取会话、自动按用户名命名账号、写入钥匙串——不需要再去找 `.ROBLOSECURITY`。登录页跑在非持久化的 `WKWebsiteDataStore` 里，关窗即销毁，加第二个号时是干净环境。

**多开。** 每个账号一份 APFS clonefile 副本（写时复制，几乎不占额外空间），改独立 bundle id、解除单实例限制、ad-hoc 重签，再用账号会话换 `rbx-authentication-ticket` 拉起客户端。会话通过一个预编译的 cookie 助手交给 CFNetwork 自己写进副本的 cookie 库，避免手写 `binarycookies` 写坏。

**FFlag 预设。** 9 项中英双语预设：抗锯齿、纹理质量、光照技术、帧率上限（5–240）、渲染分辨率、灰色天空、去掉草地、强制最低画质、关闭 DPI 缩放。另有手写模式、一键「性能优先」与「恢复默认」。帧率写进副本，不动全局 `GlobalBasicSettings_13.xml`。

**账号与实例管理。** 右键：启动 / 检查登录 / 重命名 / 在 Finder 显示 / 删除。重命名会自动迁移 Keychain 条目、cookie 库与副本 bundle id。侧栏绿点表示运行中，可逐个停止或全部关闭。

**窗口预览。** 工具栏「预览」用 ScreenCaptureKit 抓取每个运行实例的缩略图，1.5 秒刷新。

**其它。** 版本检测（对比官方最新版本）、placeId 解析成游戏名、每账号记住 placeId/尺寸/fps、中英双语界面、浅色/深色/跟随系统、5 种强调色、菜单栏常驻、悬停提示、窗口自动排列。

## 分发

DMG 内置 CPython 3.12 运行时和预编译的 cookie 助手，朋友的 Mac 不需要装命令行工具。

## 安装

下载 `Roost-1.0.0.dmg`，拖进 `Applications`。首次打开会被 Gatekeeper 拦，右键 →「打开」即可（或 `xattr -dr com.apple.quarantine /Applications/Roost.app`）。

**要求**：macOS 13+，Apple 芯片。

## English

First distributable release.

- **Embedded official sign-in** — click `+`, sign in on Roblox's own page (2FA supported); the session is captured, named after your username and stored in the Keychain. No cookie hunting.
- **Multi-instance** — one APFS clone per account with its own bundle id and cookie store; sessions are handed to CFNetwork by a tiny prebuilt helper instead of hand-writing `binarycookies`.
- **9 bilingual FFlag presets** (MSAA, textures, lighting, FPS cap 5–240, render resolution, gray sky, no grass, lowest quality, DPI) plus raw editing and one-click "performance" / "reset".
- **Accounts & instances** — right-click to launch / check / rename / reveal / delete; rename migrates the Keychain item, cookie store and clone bundle id.
- **Live window previews** via ScreenCaptureKit, version check, place-name lookup, per-account place/size/fps, bilingual UI, menu bar extra.
- DMG bundles CPython and the prebuilt helper, so no Xcode Command Line Tools are required.
